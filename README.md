"# Rolling Thunder" 
remake of Rolling Thunder for Amiga AGA, fastmem & whdload required

Requires a 2-button joystick, or the keyboard

Credits:

  sound conversion for the Amiga.
- Claude A.I.: big help with ripping graphics, multi-cpu sync, 
  async blitting & a lot of code bug hunting
- no9: music
- PascalDe73: icons
- Konami: original game

Instructions:

5: insert coin
1/2: start game
arrows/joystick: move
red/ctrl: shoot
blue/alt: jump
ESC: quit current game
